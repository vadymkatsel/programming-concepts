Цей репозиторій містить вихідний код, матеріали та конфігурації для інтерактивного вебсайту, що супроводжує курс **"Основи програмування"**. Проєкт розроблений для університетських студентів-початківців і зосереджений на поєднанні теоретичних концепцій з практикою.

## 🛠 Стек технологій

Проєкт побудований на базі сучасних інструментів публікації та веб-розробки:

- **[Quarto](https://quarto.org/):** Основний фреймворк для генерації статичного сайту з Markdown/Jupyter документів (`.qmd`).
- **Quarto Live (Pyodide):** Забезпечує інтерактивне виконання Python-коду безпосередньо в браузері (без потреби в серверному бекенді).
- **Vanilla HTML / CSS / JS:** Кастомний, високопродуктивний інтерфейс з використанням сучасних дизайн-патернів (Glassmorphism, Dark/Light modes). Важкі фреймворки (Bootstrap, Tailwind) не використовуються для розширення UI.
- **Python 3.10+:** Використовується для генерації статичних прикладів та задач (залежності: `jupyter`, `pandas`, `matplotlib`, `numpy`, `great-tables`).
- **GitHub Actions & Pages:** Автоматизований CI/CD конвеєр для збірки та безкоштовного хостингу.

## 📂 Структура репозиторію

Репозиторій логічно розділений на конфігурації, налаштування штучного інтелекту та навчальний контент.

```text
├── .agents/                  # 🤖 Контекст, правила, агенти та скіли для Antigravity CLI
├── .github/workflows/        # ⚙️ CI/CD пайплайни
├── _extensions/              # 🔌 Розширення Quarto
├── _freeze/                  # ❄️ Кеш обчислень Quarto
├── courses/                  # 📚 Навчальні матеріали, поділені на спеціалізації:
│   ├── be-course/            #    - Бізнес Економіка
│   ├── ebd-course/           #    - Економіка та Великі дані
│   └── math-course/          #    - Математика
├── index.html / index.css    # 🏠 Кастомна лендінг-сторінка курсу
├── style.css / script.js     # 🎨 Глобальні стилі та ізольована логіка інтерфейсу
├── _quarto.yml               # 🛠 Головний конфігураційний файл проєкту
└── requirements.txt          # 📦 Python-залежності
```

## ⚡ Ключові архітектурні рішення

1. **Інтерактивність без бекенду (`{pyodide}`)**
   Розділи "Демо" використовують інтерактивні клітинки Quarto Live. Студенти можуть змінювати та виконувати код прямо на сайті. Всі обчислення відбуваються в їхньому браузері через WebAssembly.

2. **Оптимізований CI/CD**
   Пайплайн на GitHub Actions використовує агресивне кешування. Завдяки `actions/cache` для пакетів `pip` та директорії `_freeze`, Quarto не перераховує незмінені `.qmd` файли, скорочуючи час збірки з кількох хвилин до лічених секунд.

3. **Агентна екосистема Antigravity (`.agents/`)**
   Розвиток проєкту підтримується через Antigravity CLI (`agy`). У папці `.agents/` зібрані спеціалізовані агенти (`educational-designer`, `educational-critic`, `web-architect`), правила (`rules/`) та скіли (`/generate-practice`), які забезпечують автоматизовану генерацію навчального контенту за суворими педагогічними стандартами.

## 🚀 Локальне розгортання

Якщо ви хочете додати новий контент або протестувати зміни локально:

1. **Встановіть інструменти:**
   - [Quarto CLI](https://quarto.org/docs/get-started/)
   - Python 3.10+

2. **Клонуйте репозиторій та встановіть залежності:**

   ```bash
   git clone https://github.com/vadymkatsel/programming-concepts
   cd programming-concepts
   pip install -r requirements.txt
   ```

3. **Запустіть режим розробки (Live Preview):**

   ```bash
   quarto preview
   ```

   _Quarto автоматично відстежуватиме зміни у файлах і оновлюватиме сторінку в браузері._

4. **Генерація статичного сайту (опціонально):**
   Щоб зібрати фінальні файли сайту (зазвичай у папку `docs/` або `_site/`), виконайте:
   ```bash
   quarto render
   ```
